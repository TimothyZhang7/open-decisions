# Third-party software and models

Open Decisions code is MIT-licensed. Dependencies and model weights retain their
own licenses. No model weights are included in source distributions or wheels.

- [Qwen3-VL-4B-Instruct](https://huggingface.co/Qwen/Qwen3-VL-4B-Instruct):
  Qwen team's model, Apache-2.0.
- [MLX 4-bit conversion](https://huggingface.co/mlx-community/Qwen3-VL-4B-Instruct-4bit):
  MLX Community model repository, Apache-2.0. Revision recorded in
  `model-manifest.json` and the download command.
- [MLX-VLM](https://github.com/Blaizzy/mlx-vlm): MIT.
- [MLX](https://github.com/ml-explore/mlx): MIT.
- [MLX-LM](https://github.com/ml-explore/mlx-lm): MIT.
- [PyTorch](https://github.com/pytorch/pytorch): BSD-3-Clause.
- [SmolLM2-135M-Instruct](https://huggingface.co/HuggingFaceTB/SmolLM2-135M-Instruct): Apache-2.0; downloaded separately for the portable-backend check.
- [Transformers](https://github.com/huggingface/transformers): Apache-2.0.
- [Pydantic](https://github.com/pydantic/pydantic),
  [FastAPI](https://github.com/fastapi/fastapi): MIT.
- [Uvicorn](https://github.com/encode/uvicorn): BSD-3-Clause.
- [Pillow](https://github.com/python-pillow/Pillow): MIT-CMU.

The Choice, Noul and Score interface is informed by TypeSafe's public
[Choice](https://docs.typesafe.ai/primitives/choice),
[Noul](https://docs.typesafe.ai/primitives/noul), and
[Score](https://docs.typesafe.ai/primitives/score) documentation.
This implementation uses Qwen weights. It contains no TypeSafe model, SDK, or
service dependency and has no affiliation with TypeSafe or Qwen.

The fixture images are generated by `examples/evaluate_model.py` and are covered
by this project's MIT license.
